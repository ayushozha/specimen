Privacy Policy

Effective November 23, 2026

What Specimen processes

Specimen starts scanning when you select Capture everything, Capture a section or Scan page. It processes the selected tab on your device. A scan can read the page URL and title, rendered content, layout, styles, web technologies, and related resources. It can scroll to load content and dismiss recognized cookie prompts using reject or essential-only options. Recording page-load motion can reload the page.

Captures may include screenshots, page markup, styles, media, and a browser-generated page snapshot where supported. If you enable motion capture or record an interaction, captures may also include videos, frame images, pointer positions, button states, and timing. Captured pages and recordings can contain private information visible in the tab. With motion capture on, captures can also include the shader code the page compiles for its canvas effects.

Permissions and network requests

Chromium uses the browser’s debugging permission to inspect and capture the selected tab. Firefox and Safari can ask for optional access to all sites when you start a capture. Specimen uses this permission to read stylesheets and assets related to your selected page. Some assets may be requested from their original hosts without credentials. Those hosts can receive ordinary request information, such as an IP address.

Storage, exports, and sharing

The extension has no account, analytics, advertising, or capture server. Specimen does not transmit captures to its developer, design tools, or AI services. It holds captures in the panel session until the panel closes or reloads. On Safari, it uses browser session storage for window docking information.

When you choose an export, Specimen writes the file or clipboard item you requested. Files you save stay where you save them until you remove them. Clipboard contents remain under your browser and operating system’s control. Third-party tools handle content according to their own policies when you import or paste it there. Exported HTML may reference resources at the original site. Review exports before sharing them.

Chrome Web Store Limited Use

Specimen uses information received from Chrome extension APIs in accordance with the Chrome Web Store User Data Policy, including its Limited Use requirements.

Website and contact

This website is served from a Hostinger VPS. The server and hosting provider may process ordinary request information to deliver and troubleshoot the site. For questions about Specimen, use GitHub Issues, which GitHub handles under its privacy statement. Avoid attaching private captures or other sensitive information to public issues.
